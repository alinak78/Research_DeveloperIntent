# Fresh local generation pilot: design fixed before generation

Model: installed Ollama llama3.2:1b; record server model digest and quantization before generation. No downloaded or cloud models. Researcher-authored synthetic tasks, not source-grounded institutional policies.

Twelve task templates: four field variants each for optional-field normalization, duplicate-looking records, and lookup-assisted cleaning. Variants within a family are dependent; there are only three operation families, not twelve independently sourced workflows. Both conditions use the same task and ordinary-case examples. Ambiguous condition omits the reference policy; explicit condition adds it. Public tests use ordinary rows where plausible retention interpretations coincide. Reference tests expose missing values, distinct IDs sharing values, repeated IDs, and unmatched lookups as applicable. Reference policy is preservation for optional fields and lookup misses; deduplication keeps the first row for each exact ID, never collapsing different IDs on equal field values. All policies are researcher choices, not externally legitimized.

Five requested generations per template/condition, seeds 17,29,43,61,89. Temperature 0.8, top_p 0.9, num_predict 512, num_ctx 2048. Total 120 fresh generations, randomized request order using seed 20261101. Shared seed schedule makes conditions paired by design but does not guarantee identical random trajectories across prompts. No model-output-driven prompt edits or repairs. Preserve original responses, errors, token counts, settings and timestamps.

Candidate evaluation uses a restricted Python subset: imports, dunder names, unsupported attribute access, module-level statements other than function definitions, and unsupported syntax are rejected. Evaluate allowed functions in isolated Python (-I -S) under macOS sandbox-exec, denying networking, filesystem writes, and child-process creation; restricted builtins and AST screening disallow arbitrary host-file access. Read-only host visibility is not a production container boundary. CPU limit 2 seconds, wall limit 4 seconds per output batch, memory limit where supported. Reject unsupported code as an evaluation failure and report it separately. No candidate is executed outside this path.

Report generation failures, evaluation rejections, public pass, full reference compliance, joint public-pass/reference-fail, task-macro conditional IVR and micro IVR, and family rates. Undefined IVR remains undefined. For condition contrast report paired full-compliance difference per task/family, but no confirmatory significance claim or population CI from only three synthetic families. One model and researcher-authored fixtures cannot establish field validity, fairness harms, or a frontier-model comparison.
