# Related work and bounded novelty

Primary sources checked October 28, 2026. This is a focused bibliography, not an exhaustive priority search.

| Work | Relevance and distinction |
|---|---|
| Selbst et al., *Fairness and Abstraction in Sociotechnical Systems*, FAT* 2019. [Author paper](https://friedler.net/papers/sts_fat2019.pdf), DOI 10.1145/3287560.3287598 | Abstraction traps motivate retaining institutional policy and social actors. Extra tests alone cannot establish fairness. |
| Jacobs and Wallach, *Measurement and Fairness*, FAccT 2021. [Paper](https://arxiv.org/abs/1912.05511), DOI 10.1145/3442188.3445901 | Construct validity motivates separating latent intent from observed requirement nonconformance. |
| Sambasivan et al., *Data Cascades in High-Stakes AI*, CHI 2021. [Research publication](https://research.google/pubs/everyone-wants-to-do-the-model-work-not-the-data-work-data-cascades-in-high-stakes-ai/), DOI 10.1145/3411764.3445518 | Grounds the significance of organizational data practices generally, not a particular proposed intake scenario. |
| Liu et al., *Is Your Code Generated by ChatGPT Really Correct?*, NeurIPS 2023. [Paper](https://arxiv.org/abs/2305.01210) | EvalPlus already studies stronger executable code tests. More hidden tests are not the novelty here. |
| Mu et al., *ClarifyGPT: Empowering LLM-based Code Generation with Intention Clarification*, 2023 preprint. [Paper](https://arxiv.org/abs/2310.10996) | Clarification is established prior work. The proposed distinction concerns policy provenance and retention consequences. |

Candidate contribution: a requirement-provenance audit of record-retention choices, combining a traceable policy-construction process, executable nonconformance measurement, and matched information conditions in a grounded context. The algorithm pilot does not establish that contribution. Before any priority claim, search later code-agent clarification, requirements engineering, sociotechnical audits, and preprocessing studies. No claim of being first is made.
